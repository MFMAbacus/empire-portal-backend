# Empire World - Customer Service Portal - Server Application

Server application for Empire World's Customer Service Portal.

# Installation

```bash
# Install dependencies.
yarn install

# Create and update .env file
cp .env.example .env

# Run in development mode.
yarn dev

# Run in production mode.
yarn prod

# Run tests.
yarn test

# Watch test a specific file.
yarn test:watch

# Run test coverage.
yarn test:coverage

# Lint.
yarn lint
```
